Operating system, from scratch

SinOS

A 32-bit operating system I wrote from zero in C and assembly: its own bootloader, interrupts, memory paging, multitasking, user programs, a FAT16 disk driver, a shell, pixel graphics, and a snake game. This is the real thing, booting inside a PC emulator in your browser.

Press the button to boot.

Try it

  1. Click Boot SinOS and wait for sinos>.
  2. Click the screen so it gets your keyboard.
  3. Type game and press Enter.

Other commands: help, ls /, cat /readme.txt, run hello, ps, ls /disk.

Sin Snake

  • Arrows or WASD: steer
  • P: pause
  • Q or Esc: back to the shell
  • Space: play again after a crash

The high score is saved to SinOS's disk, but here that disk lives in your browser's memory, so it resets when you reload the page.

Desktop keyboard needed. Runs on v86 (BSD-2-Clause, licence) with SeaBIOS and the LGPL VGA BIOS (LGPL-3.0).
